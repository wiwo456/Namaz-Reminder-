Web preview for the Namaz Reminder project.

How to run:

1. Open a terminal in the project root.
2. Run `python3 -m http.server 8000`.
3. Visit `http://localhost:8000/web/`.

What this preview does:
- Shows the full phone-style app flow in the browser
- Uses saved home coordinates or browser location
- Stores settings in local browser storage
- Highlights the next prayer and shows a live countdown
- Includes a widget-style preview card
- Can trigger browser notifications while the page remains open

What this preview does not do yet:
- Install a real Android widget on your phone
- Run background updates after the browser tab is closed
